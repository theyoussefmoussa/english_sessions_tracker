# English Session Attendance Tracker

A lightweight attendance management tool built with Python and PostgreSQL to record and manage student attendance in English sessions.

## Features

- Student management
- Student grade classification (Fundamentals and Grades 1–7)
- Attendance tracking (planned)
- Attendance history (planned)
